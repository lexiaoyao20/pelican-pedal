# Pelican Pedal · 鹈鹕骑行记

**[在线试玩](https://lexiaoyao20.github.io/pelican-pedal/)**

帮一只系着红围巾的鹈鹕骑完 1,200 米海岸公路。从海风栈道出发，穿过彩帆渔港，抵达暮光灯塔时，你会收到一张印着里程和鱼获的明信片。

![灯塔海岸的场景原画，白帆驶过礁石，红白相间的灯塔立在岸上](assets/art/lighthouse.webp)

## 玩法

鹈鹕会自己踩踏板。路障前的小鱼排成一道弧线，跟着鱼群起跳，就能越过木箱、螃蟹和浮标。来不及跳时也可以用冲刺撞开路障，冲刺每 5 秒可用一次。

每局有三颗心，撞上路障会失去一颗。普通小鱼计 1 条，金鱼计 3 条。浏览器会保存你的最远骑行距离。

| 动作 | 键盘 | 触屏 |
| --- | --- | --- |
| 跳跃 | 轻按空格、`↑` 或 `W` | 轻点画面或跳跃按钮 |
| 滑翔 | 起跳后继续按住跳跃键 | 按住画面或跳跃按钮 |
| 冲刺 | `→`、`D` 或 `Shift` | 点“冲刺” |
| 暂停或继续 | `P` | 点游戏右上角的暂停或继续按钮 |
| 切换全屏 | `F` | 点游戏右上角的全屏按钮 |

## 本地运行

下载并解压仓库后，用浏览器打开根目录的 `index.html` 就能离线游玩。要通过本地服务器预览，可以在同一目录用 Python 3 运行以下命令。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

服务启动后即可[打开本地游戏](http://127.0.0.1:8000/)。

## GitHub Pages 发布

本仓库包含构建好的游戏脚本 `build/game.js`，图片和字体位于 `assets/`。在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`。推送到 `main` 后，GitHub Pages 会自动更新站点。
